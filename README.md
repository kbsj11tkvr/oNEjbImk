# 项目简介

## 核心功能
- 基于YOLOv8的道路坑洼检测系统，支持对道路坑洼进行自动识别和检测
- 支持多种输入源检测：单张图片、图片文件夹、视频文件和本地摄像头
- 提供用户友好的图形界面，可实时显示目标位置、目标总数和置信度等信息
- 支持批量检测功能，可查看并保存所有检测结果
- 允许自定义检测参数，包括置信度和IOU阈值
- 提供模型选择功能和显示选项（标签和原图）

## 适用场景
- 道路养护管理部门进行路面状况评估
- 城市基础设施巡检和维护
- 道路安全监测和预警系统
- 智能交通管理系统中的路况分析

## 技术特点
- 采用YOLOv8作为核心检测算法，具有高精度和实时性
- 使用PyQt5构建图形用户界面，操作简便直观
- 兼容多种开发环境（Pycharm+Anaconda或VSCode+Anaconda）
- 预配置完整环境，包含Python 3.9、OpenCV、PyTorch等必要依赖
- 内置2000张道路坑洼标注数据集，涵盖pothole一类目标
- 提供完整源码、训练好的模型、数据集和详细运行教程
